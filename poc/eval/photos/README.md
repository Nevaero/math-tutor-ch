# Photos de test (non versionnées)

Déposer ici des photos d'énoncés **produites en interne** (écrites à la main ou imprimées par nos soins),
pas des pages de manuels (droit d'auteur, specs/08 §8.5), et sans nom d'élève.

Varier : manuscrit / imprimé, éclairage, angle, plusieurs exercices par page, figures géométriques.

Test manuel : `python -m leo.cli --photo eval/photos/<fichier>.jpg --debug`
