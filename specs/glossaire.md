# Glossaire

| Terme | Définition |
| --- | --- |
| **PER** | Plan d'études romand — référentiel commun de la scolarité obligatoire des cantons francophones |
| **MSN** | Domaine « Mathématiques et Sciences de la nature » du PER |
| **MER** | Moyens d'enseignement romands (manuels officiels) |
| **H (1H–11H)** | Numérotation HarmoS des années de scolarité obligatoire ; 9H–11H = Cycle 3 (secondaire I) |
| **Cycle 3** | 9H, 10H, 11H (environ 12–15 ans) |
| **CO** | Cycle d'orientation — nom du secondaire I (9e–11e) à Genève |
| **VP / VG** | Voie prégymnasiale / voie générale du secondaire I vaudois |
| **Secondaire II / Gymnase** | Formation post-obligatoire menant à la maturité gymnasiale ; appelée « Gymnase » dans le canton de Vaud, « Collège de Genève » à Genève |
| **PII** | Personally Identifiable Information — donnée permettant d'identifier une personne |
| **Profil d'apprentissage** | Données pédagogiques pseudonymes sur un élève (maîtrise des notions, erreurs récurrentes, style) servant à adapter le tuteur |
| **OS** | Option spécifique de la maturité (ex. Physique et applications des mathématiques) |
| **nLPD** | Nouvelle loi fédérale sur la protection des données (en vigueur depuis le 1er septembre 2023) |
| **PFPDT** | Préposé fédéral à la protection des données et à la transparence |
| **AIPD** | Analyse d'impact relative à la protection des données |
| **LDA** | Loi fédérale sur le droit d'auteur |
| **CLOUD Act** | Loi américaine permettant aux autorités US d'accéder aux données détenues par des fournisseurs US, y compris hors des États-Unis |
| **VLM** | Vision-Language Model — modèle capable de traiter image et texte |
| **Open-weight** | Modèle dont les poids sont publiés et peuvent être auto-hébergés |
| **RAG** | Retrieval-Augmented Generation — injection de contenus externes dans le contexte du modèle |
| **Sandbox** | Environnement d'exécution isolé pour le code généré |
| **SymPy** | Bibliothèque Python de calcul formel |
| **EDO** | Équation différentielle ordinaire |
| **ASR / TTS** | Reconnaissance vocale / synthèse vocale |
